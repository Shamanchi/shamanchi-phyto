# Спутник Фито — демо-маркетплейс фито-ниши (Сборка А)

Демонстрационный сайт-магазин вымышленного фито-бренда «Спутник Фито»: полноценный
маркетплейс-каркас (каталог, карточки, корзина, оформление, демо-заказ) поверх
доверительного лендинга с живым фоном. Это витрина «так выглядит сайт вашего бизнеса
на нашем уровне» для владельцев фито-магазинов и брендов БАД.

Сборка А — эталонная кодовая база: из неё клонируется Сборка Б (реальный магазин
заказчика) с заменой только данных (`data/products.json`) и констант бренда
(`lib/site.js`). Бренд и словари в компоненты не зашиты.

**Основной сайт студии:** [Shamanchi / orbit](http://shamanchi.ru/) · телеграм
[@shamanchi_dev](https://t.me/shamanchi_dev) · почта shamanchi_dev@mail.ru

- Стек: Next.js 15 (App Router) + Tailwind CSS, статический экспорт `output: "export"`.
- Деплой: GitHub Pages — https://shamanchi.github.io/shamanchi-phyto/
- Живой фон: tsParticles (`@tsparticles/engine` + `@tsparticles/slim` + `@tsparticles/react`),
  canvas 2D без WebGL. Пыльца fullscreen (50 частиц, ~30 на мобильных), листья только
  в hero на десктопе; `prefers-reduced-motion` — статичный фон; инициализация после
  контента (window load → requestIdleCallback).
- Маркетплейс в демо-режиме: каталог (подборки/фильтры/сортировка/поиск), карточка
  (состав, приём, цена, похожие), корзина (количество, удаление, промокод), оформление
  (контакты → доставка → оплата) до шага «демо-заказ принят», история заказов
  в localStorage и повтор заказа. Оплата не проводится: интерфейс готов под ЮKassa/Prodamus.
- Без бэкенда: товары в `data/products.json`, корзина/промокоды/заказы — `localStorage`.
- Все ассеты локальные: шрифты Cormorant + Manrope (woff2), SVG-арт товаров и врача.

## Структура

- `app/` — layout (SEO/OG, живой фон), страницы: `/` (лендинг), `/catalog`,
  `/product/[id]`, `/cart`, `/checkout`, `/order-success`, `/account`
- `components/` — секции лендинга + `live/` (пыльца, листья) + `catalog|product|cart|checkout|account`
- `lib/site.js` — бренд, SEO, словари маркетплейса (форматы/задачи/цены/промокоды/доставка/оплата)
- `lib/shop.js` — чистые помощники каталога/корзины/заказов
- `data/products.json` — 8 демо-товаров (вымышленный бренд)
- `scripts/` — `fetch-assets.mjs`, `gen-product-art.mjs`, `serve-static.mjs`
- `tests/acceptance.mjs` — приёмочный сценарий на headless Chrome (Playwright-core)
- `.github/workflows/deploy.yml` — сборка и публикация на GitHub Pages

## Команды

```bash
npm install
npm run dev        # разработка — http://localhost:3000/shamanchi-phyto/
npm run build      # статическая сборка в ./out
npm run preview    # предпросмотр собранного экспорта
npm run test:acceptance   # после npm run build; требуется установленный Chrome/Edge
```

## Демо-режим и обезличенность

«Спутник Фито», врач-основатель, товары и отзывы — вымышленные. Сайт ничего не продаёт
и не собирает данные: корзина, промокоды, заказы и форма заявки работают локально
в браузере (localStorage). Формулировки соответствуют правилам рекламы БАД.

Ключевое сообщение демо-блока: «Мы делаем дизайн, который работает с вашей целевой
аудиторией». Заявка ведёт на телеграм @shamanchi_dev и почту shamanchi_dev@mail.ru.

## Смена адреса GitHub Pages / бренда

Имя проекта задано в `basePath` (`next.config.mjs`) и `SITE_PATH` (`lib/site.js`).
Для новой сборки меняются только `lib/site.js` (бренд, контакты, словари, промокоды,
доставка) и `data/products.json` (каталог) — компоненты и страницы остаются теми же.
