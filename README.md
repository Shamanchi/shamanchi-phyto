# Спутник Фито — эталонный фито-лендинг

Демонстрационный одностраничный сайт-магазин вымышленного фито-бренда «Спутник Фито».
Живой пример того, как выглядит сайт для ниши «товары здоровья», когда он строится на
доверии, а не на акциях: лицо врача-основателя в первом экране, подбор по задаче,
курсы на месяц, честные цены и безопасные формулировки.

Второе назначение — продающий спутник: тёмный блок «Это демонстрация» превращает
владельца похожего бизнеса в заявку на разработку (телеграм / почта) без бэкенда.

- Стек: Next.js (App Router) + Tailwind CSS, статический экспорт `output: "export"`.
- Деплой: GitHub Pages — https://shamanchi.github.io/shamanchi-phyto/
- Без бэкенда: товары в `data/products.json`, корзина и квиз — `localStorage`.
- Все ассеты локальные: шрифты Cormorant + Manrope (woff2, кириллица + латиница),
  арт товаров и портрет врача — сгенерированные SVG (нет внешних запросов).

## Структура

- `app/` — layout (SEO/OG), страница, `globals.css`, self-hosted `fonts.css`
- `components/` — секции: Nav, Hero, Quiz, Showcase, CartDrawer, Founder, Craft,
  Reviews, DemoBlock (тёмный терминальный блок-заявка), Footer
- `data/products.json` — 8 демо-товаров
- `scripts/` — `fetch-assets.mjs` (шрифты), `gen-product-art.mjs` (SVG-упаковки),
  `serve-static.mjs` (предпросмотр экспорта)
- `tests/acceptance.mjs` — приёмочный сценарий на headless Chrome (Playwright-core)
- `.github/workflows/deploy.yml` — сборка и публикация на GitHub Pages

## Команды

```bash
npm install

# разработка — http://localhost:3000/shamanchi-phyto/
npm run dev

# статическая сборка в ./out
npm run build

# предпросмотр собранного экспорта — http://localhost:4173/shamanchi-phyto/
npm run preview

# приёмочный сценарий (требует собранный ./out и установленный Chrome/Edge)
npm run test:acceptance
```

## Палитра «живой аптеки»

- фон — тёплая бумага `#F7F3EA`; текст-«чернила» `#22301F`
- акценты — травяной зелёный `#3E6B35`, шалфей `#8FA98A`
- CTA и цены — янтарь `#C98A2C` (тексты цен — затемнённый янтарь для контраста AA)
- единственное тёмное место — терминальный блок «Это демонстрация» в стиле Shamanchi/orbit

## Смена адреса GitHub Pages

Имя проекта задано в двух местах: `basePath` в `next.config.mjs` и `SITE_PATH` в
`lib/site.js`. При переименовании репозитория поменяйте оба значения
(или задайте `NEXT_PUBLIC_BASE_PATH` при сборке) и канонический URL в `app/layout.jsx`.

## Демо-дисклеймер

«Спутник Фито», врач-основатель, товары и отзывы — вымышленные. Сайт ничего не продаёт
и не собирает данные: корзина, квиз и форма заявки работают локально в браузере.
Формулировки соответствуют правилам рекламы БАД.
